# Elise wird 9 🎉

Eine kleine Geburtstags-Wunschliste für Elise.

## GitHub Pages
1. Neues GitHub-Repository erstellen.
2. `index.html` hochladen.
3. Unter **Settings → Pages** als Quelle den Branch `main` und `/ (root)` auswählen.
4. Die angezeigte GitHub-Pages-Adresse öffnen.

Die Amazon-Links führen direkt zu den jeweiligen Produkten.
